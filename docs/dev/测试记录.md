| 4 | `sdkmanager --install platform-tools platforms;android-36 build-tools;36.0.0` | ❌ **失败**（见下） |
| 5 | `sdkmanager --licenses`（喂 y） | ✅ `All SDK package licenses accepted` |
| 6 | 重跑 `--install` | ✅ exit 0 |

### ❌ 失败项 1：许可证未接受导致「假成功」

**现象**：
```
Accept? (y/N): Skipping following packages as the license is not accepted:
Android SDK Build-Tools 36
Android SDK Platform-Tools
Android SDK Platform 36
```
**但 exit code 为 0**。

**原因**：`sdkmanager --install` 在非交互环境下遇到未接受的许可证时，会跳过这些包，却仍返回 0。

**教训**：**不能只看 exit code**。必须验证产物文件真实存在。

### ✅ 最终验证（产物存在性）

| 文件 | 结果 |
| --- | --- |
| `F:\Android\Sdk\platform-tools\adb.exe` | ✅ True |
| `F:\Android\Sdk\build-tools\36.0.0\aapt2.exe` | ✅ True |
| `F:\Android\Sdk\platforms\android-36\android.jar` | ✅ True |
| `F:\Android\Sdk\licenses` | ✅ 存在 |

**结论**：SDK 安装完成且**经产物验证**（非仅凭 exit code）。
