1这一屏解决什么

把「手机浏览器跑桌面 Web UI」换成「原生 App 直接说 Typert RPC」。对照你的原话：

你的痛点本原型的做法
重开网页＝重启凭证落盘（Keystore），冷启动不重新配对、不加载任何插件
加载时间很长不再下载/执行桌面 SPA 与插件 bundle，只取 JSON + WS
还要渲染 UI原生 Compose UI，一次渲染，不做桌面 UI 的二次改写
交互性差原生抽屉做会话侧栏（现状被 mobile-adapt 压成 0 宽，手机上根本没有）

2每屏对应的真实接口

界面调用通道
配对页POST {base}/api/pair/accept {token}直连（不走 /remote）
工作区列表workspace/follow 流mux
会话列表/状态session/control 流mux
聊天历史session/follow 流 → snapshotmux
翻更早session/page {beforeSeq}HTTP
发送消息session/prompt {mode:'queue'}HTTP
中止session/cancelHTTP
改动文件卡片GET /remote/api/changes.summary?sessionId=&seq=HTTP（非 RPC）
某轮 diffGET /remote/api/changes.diff?sessionId=&seq=&index=HTTP（非 RPC）
文件查看页workspaceFiles/read · readBytes · statHTTP

单次调用固定为：
POST {base}/remote/api/<ns>/<method>
头部 x-dsh-remote-device: <deviceId>，body {"type":"client-request","rpcId":uuid,"method":"ns/method","payload":{"args":{…}}}。

3界面结构

  • 配对页 — 扫码 / 粘令牌 / 手填地址；地址栏下方实时探测可达性
  • 工作区列表 — 工作区可展开显示其会话；运行中会话带脉冲点；支持下拉刷新
  • 会话抽屉 — 工作区 / 最近会话 / 已置顶 / 已归档，底部显示 mux 状态与帧计数
  • 聊天页 — 顶部标题与运行状态；消息区分「你 / DSH」；助手回复按 Markdown 渲染；工具调用折叠；轮次末尾一张「已编辑 N 个文件」卡片；底部输入框
  • 文件查看页 — 三页签（改动 diff / 当前全文 / Markdown 预览），顶部显示路径、版本与增删行数
  • 连接状态条 — 已连接（绿）/ 重连中（黄闪）/ 已断开（红），断线不清空界面
  • 设置页 — 连接、同步、外观、协议调试、解除配对

4交互细节（可在左侧试用）

  • 点 扫描二维码配对 → 模拟配对成功，进入工作区列表
  • 点工作区标题 → 展开/收起该工作区的会话
  • 点任意会话 → 进入聊天，历史消息逐条出现，最后一条是流式 Markdown（标题/列表/表格/代码块）
  • 点回复下方「已编辑 N 个文件」卡片里的任意一行 → 打开文件查看页（改动 diff）
  • 文件查看页可切换 改动 diff / 当前全文 / Markdown 预览 三个页签
  • 点回复正文里的行内文件链接（如 需求文档.md）同样可打开文件查看页
  • 在输入框输入并发送 → 先出现你的气泡，再出现「思考中…」→ 流式 Markdown 回复
  • 回复生成中，右下角按钮变为中止（对应 session/cancel）
  • 左上 ☰ 打开会话抽屉（现状 Web 端缺失的功能）

6富文本与文件查看（回答你的问题）

你问的三件事——能不能显示 markdown、能不能看到编辑的文件、能不能点开看——都能做，而且全部走已核实的真实接口。去聊天屏看：最后一条回复就是 Markdown 渲染结果（标题/列表/表格/引用/代码块/行内代码），下面那张卡片就是「已编辑 N 个文件」。

两条必须知道的限制（不是 bug）：

  • Host 重启后，旧轮次没有改动卡片和 diff —— changes.summary 返回 404。此时降级为「工具调用推断出的文件行 + 当前全文查看」。
  • 非 git 仓库里，纯 shell 命令改的文件不会进卡片 —— 只统计 write/edit/str_replace_editor 的改动。

左侧 #file 可直接打开文件查看页（三页签：改动 diff / 当前全文 / Markdown 预览）。

7本原型未覆盖（请确认是否要）

  • 终端 / SSH（/remote/sidebar/ws/* 通道）
  • 插件管理、自更新 —— 服务端硬性拒绝，做不了
  • 文件编辑（只读服务，无写接口）
  • 模型切换、图片附件、待办与目标面板、向用户提问面板
  • 多套连接配置管理、多设备
